영어 퀴즈 PWA

설치 조건: PWA 설치 기능은 HTTPS 주소에서 열어야 정상 동작합니다.
1) ZIP 압축을 풉니다.
2) GitHub Pages / Netlify / Cloudflare Pages 등 정적 웹 호스팅에 폴더 전체를 업로드합니다.
3) 휴대폰 Chrome 또는 삼성 인터넷으로 HTTPS 주소에 접속합니다.
4) 화면의 “앱으로 설치” 또는 브라우저 메뉴의 “앱 설치/홈 화면에 추가”를 누릅니다.
5) 설치 후 홈 화면에서 독립 앱처럼 실행됩니다.
6) 최초 접속 후 오프라인 사용도 가능합니다.

모드: 중등 / 고등 / 대학 / 심화 / 원어민 일상 프리토킹
각 모드는 문제를 무작위로 반복하여 횟수 제한 없이 계속 풀 수 있습니다.

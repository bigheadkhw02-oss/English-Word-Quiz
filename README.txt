영어 퀴즈 PWA v3 — 190,000문제용 구조

이 패키지는 190,000문제를 안정적으로 수용하기 위한 앱 구조입니다.
현재 pack_*.js에는 기능 확인용 샘플 데이터만 들어 있습니다. 190,000개의 실제 학습 데이터가 전부 채워진 패키지는 아닙니다.

왜 이렇게 나눴나
- 각 학습 목록을 최대 10,000개짜리 별도 pack 파일로 분리
- 선택한 pack만 로드하고 캐시
- 진행률은 10,000비트 bitset으로 저장
- 오답은 IndexedDB에 저장
- 앱 업데이트 시 코어 파일은 최신 버전을 받고 데이터팩은 필요할 때 로드

GitHub 업로드
기존과 동일합니다.
1. ZIP 압축 해제
2. 저장소 Code 화면 > Add file > Upload files
3. 압축 해제한 파일을 전부 선택해 업로드
4. Commit changes
5. GitHub Pages 설정은 다시 할 필요 없음
6. 배포 후 설치된 앱을 완전히 종료했다가 다시 실행

중요
- ZIP 자체를 올리지 말고 ZIP 안의 파일을 올리세요.
- pack_*.js 파일도 빠짐없이 같이 올리세요.
- 같은 이름 파일은 기존 파일을 교체하면 됩니다.

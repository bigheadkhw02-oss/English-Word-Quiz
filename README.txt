영어 퀴즈 PWA v2

추가 기능
- 각 난이도 안에서 기본 단어 / 숙어 / 파생어 / 구동사를 별도 목록으로 분리
- 원어민 일상 프리토킹은 일상 표현 / 숙어·관용표현 / 구동사로 분리
- 각 목록별 진행률 표시
- 같은 목록의 미학습 문제를 우선 출제
- 오답노트 자동 저장
- 오답만 따로 다시 풀기
- 오답 복습에서 첫 시도 정답이면 오답노트에서 제거
- 진행률·오답은 localStorage에 저장되어 앱 종료 후에도 유지
- 새 파일 배포 시 이전 PWA 캐시를 자동 정리하도록 서비스워커 개선

GitHub 업데이트 방법
1) 기존 저장소에서 Add file > Upload files
2) 이 폴더 안 파일 전체를 업로드하고 같은 이름의 파일은 교체
3) app.js와 data.js는 새 파일이므로 함께 업로드
4) Commit changes
5) 설치된 앱을 완전히 종료했다가 다시 실행
6) 필요하면 Chrome에서 GitHub Pages 주소를 한 번 새로고침

주의
현재 패키지는 기능 검증용 샘플 데이터입니다.
각 난이도 10,000개 데이터는 별도 대용량 데이터 작업으로 채워야 합니다.
앱 구조는 데이터가 커져도 분리 확장할 수 있도록 만든 버전입니다.
